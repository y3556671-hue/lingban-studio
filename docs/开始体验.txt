灵伴工坊 0.1 · Windows 本地体验版

打开方式
双击“灵伴工坊.exe”。解压后请把整个文件夹放在可以保存文件的位置。
使用 Windows .NET Framework 4.x；本机已经实际打开并验证。

可以体验什么
1. 三种内置角色：小猫、兔兔、软团子。
2. 导入自己的 PNG / JPG 图片，作为带轻动效的角色贴纸。
3. 自定义名字、活力、亲近、傲娇、口头禅和尺寸。
4. 桌宠透明置顶，轻点摸头，拖动换位置，右键打开菜单。
5. 安静陪伴、即时角色预览、本地保存、隐藏恢复。

日常操作
点击“保存角色”保留修改；正常退出也会保存。
“收起工坊”保留桌宠，可以从桌宠右键或系统托盘恢复。
关闭工坊窗口或点右键菜单“退出”会结束程序。
安静模式只关闭主动气泡；你的主动互动仍有回应。

图片导入
支持不超过 10 MB、宽高均不超过 4096 像素的静态 PNG / JPG。
推荐透明背景 PNG。图片会复制到程序旁的 data/assets 文件夹。
当前只提供贴纸和轻动效，不会把任意图片自动变成完整动画模型。

本版的边界
性格回应是离线台词规则，还没有联网 AI 聊天或语音。
“专注鼓励”是互动台词，没有计时器。
当前只保存一个角色，没有社区、创意工坊、云同步或 Steam 接入。
内置颜色和围巾暂时固定，后续可扩展编辑。
没有自动启动设置，也不会扫描桌面内容或联网上传图片。

文件
data/profile.json 是角色存档。移动时保留整个 data 文件夹。
源码文件夹提供完整 C# 源码与 Build.ps1 构建脚本。
这是开发体验版，尚未签名，也不是商业发行版本。

验证
本地存档、图片校验和性格逻辑通过自动检查。
透明窗口、隐藏恢复、气泡、退出保存通过隔离窗口检查。
实机已确认工坊能打开，滑杆即时生效并能保存。
手动桌宠拖拽和全部导入流程尚未完成实机检查。
